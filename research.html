Right now I'm interested in three tracks.

  1. Systems that keep evolving

    How do you build a system that keeps improving after it's trained, the way humans do?

    • Gets better at reasoning over time.
    • Learnable improvements in all modalities: text, images, audio.
    • Learns from its environment, not only from a fixed dataset.

  2. Cheaper tokens

    How do you make each token cheaper to produce? I'm interested in the architectures that lower that cost:

    • Mixture of experts, where only part of the model runs for each token.
    • Attention designs that shrink the memory each token needs, such as shared or compressed keys and values.
    • State-space and hybrid models, where the cost per token doesn't grow with the length of the context.

  3. Efficiency of neurons

    How do you measure whether a network is learning efficiently?

    • How much of the network does useful work.
    • How much data and compute it takes to learn a skill.
    • Whether a network could learn as well with fewer active neurons.
